# mar rojo base
ubicación: Mar Rojo, cerca de la costa de Egipto
propietario: Lex Luthor
misión: Base de operaciones y almacenamiento de recursos para la Legión del Mal. Sirve como punto de reunión para misiones en África y Medio Oriente.
descripción: Base subacuática construida por Lex Luthor y reforzada con tecnología de Brainiac. Diseñada para resistir ataques de superficie y mantener la Legión operativa en caso de conflictos internacionales.
